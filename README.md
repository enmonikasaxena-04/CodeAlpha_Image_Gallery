# 🖼️ CodeAlpha Image Gallery

A modern and responsive *Image Gallery* built using *HTML, CSS, and JavaScript*.

## ✨ Features

- Responsive Design
- Category Filters (All, Nature, City, Animals)
- Image Preview (Lightbox)
- Modern UI
- Hover Effects
- Mobile Friendly

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
